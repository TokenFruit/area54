# Architecture Decision Records

One file per decision: `NNNN-<slug>.md`, written by the **architect** agent.

An ADR records *why*, so that in six months nobody re-litigates a decision
without knowing what it cost. Decisions are immutable: to change one, write a
new ADR that supersedes it. Never edit an accepted ADR's Decision section.

**Status** moves `Proposed` → `Accepted` → `Superseded by ADR-NNNN`.

`0001-stack.md` blocks everything. No application code may be written until it
is accepted and `CLAUDE.md` carries the real commands.
